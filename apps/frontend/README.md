# WebWatcher Frontend (Nuxt 3)

This folder hosts the future Nuxt 3 dashboard. The MVP currently focuses on the backend ingestion pipeline.

## Getting started

1. Install dependencies (Node 20+ recommended):

   ```bash
   npm install
   ```

2. Start the dev server:

   ```bash
   npm run dev
   ```

> ℹ️  The Nuxt implementation will arrive in a later milestone once the ingestion API is validated.
